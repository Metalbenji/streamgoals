StreamGoals

StreamGoals is a professional goal tracking overlay system that unifies follower, subscriber, and donation events from Twitch, YouTube, TikTok, Kick, StreamElements, and StreamLabs. Track your streaming goals with beautiful, customizable progress bars that update in real-time!

What is StreamGoals?

StreamGoals is a powerful, browser-based overlay system that tracks your streaming goals across multiple platforms in real-time. Whether you're trying to reach 100 Twitch followers, 50 YouTube subscribers, or $500 in donations, StreamGoals displays beautiful progress bars that update automatically as events happen during your stream.

Installation & Setup

Make sure your Twitch and YouTube accounts are connected in Streamer.Bot before proceeding. All applications must run on the same PC.

Quick Setup Overview

  1. Set up Streamer.Bot WebSocket Server
  2. Import StreamGoals actions into Streamer.Bot
  3. Configure YouTube API (for subscriber tracking)
  4. Install optional integrations (TikTok, Kick, Donations)
  5. Launch StreamGoals and configure your goals
  6. Add overlay URL to OBS as Browser Source

Streamer.Bot WebSocket Setup

  1. Open Streamer.Bot
  2. Go to Servers/Clients → WebSocket Server
  3. Enable the WebSocket Server and ensure it's running on port 8080
  4. Note the IP address (usually 127.0.0.1 for local connections)

Importing StreamGoals Actions

StreamGoals requires specific actions to be imported into Streamer.Bot. These actions handle platform events and send data to StreamGoals.

To add an import to your bot, follow these steps:

  1. In Streamer.bot, open the Import Dialog by clicking Import on the top toolbar
  2. Paste your Streamer.bot import string into the Import String input (you can also drag & drop a file containing the import code)
  3. Review all included items and customize which items to import by Right-Clicking and toggling Include in Import
  4. Click the Import button to complete the import

Import Successful?

After importing, ensure that:

  • New StreamGoals actions are visible in your Streamer.Bot "Actions" tab
  • No major errors were reported during the import process
  • The actions are ready to work with your configured settings

YouTube Data API v3 Setup

To enable YouTube subscriber tracking, you'll need to create a YouTube API key and add it to Streamer.Bot.

  1. Go to the Google Cloud Console and sign in
  2. Create a new project or select an existing one
  3. Navigate to APIs & Services → Library
  4. Search for "YouTube Data API v3" and enable it
  5. Go to APIs & Services → Credentials
  6. Click "+ CREATE CREDENTIALS" and select "API key"
  7. Copy the API key immediately and store it securely
  8. Restrict the API key by editing it:
    • Under "API restrictions", select "Restrict key"
    • Choose "YouTube Data API v3" from the dropdown
    • Click "Save"
  9. In Streamer.Bot, go to Settings → Global Variables
  10. Create a new global variable:
    • Name: zz_youtubeApiKey
    • Value: Your API key from step 7
    • Check "Persisted" to save the variable
  11. Ensure your YouTube account is connected in Platforms → YouTube → Accounts

TikTok Integration Setup

  1. Download and install TikFinity Desktop App
  2. Open TikFinity and connect it to your TikTok account
  3. In Streamer.Bot, go to Servers/Clients → Custom WebSocket Client
  4. Find the TikFinity WebSocket connection
  5. Right-click and enable Auto-Connect and Reconnect
  6. Click Connect if not already connected

Kick.Bot Installation

  1. Download Kick.Bot from Sehelitar's repo
  2. Unzip and copy the DLLs to the dlls folder inside Streamer.Bot (create the folder if it doesn't exist)
  3. Import the action from the action.txt file included in the ZIP
  4. Restart Streamer.Bot
  5. A login window will appear - login to your Kick account

Kick Integration Note

Kick integration is beta functionality. If Kick.Bot stops working, delete the DLLs, remove the imported action, delete the Streamer.bot.exe.WebView2 folder, and reinstall following the steps above.

Donation Platform Setup

StreamElements Setup

  1. Go to StreamElements.com and login
  2. Navigate to Account settings → Channels
  3. Find Streamer.bot in integrations and click Connect
  4. Copy the JWT Token provided
  5. In Streamer.Bot, go to Platforms → StreamElements
  6. Paste the JWT Token and click Connect

StreamLabs Setup

  1. Go to StreamLabs.com and login
  2. Navigate to Settings → API Settings
  3. Generate or find your Socket API Token
  4. In Streamer.Bot, go to Platforms → StreamLabs
  5. Paste the Socket API Token and click Connect

Donation Setup Notes

  • Choose either StreamElements OR StreamLabs, not both
  • StreamGoals supports multi-currency conversion (GBP, USD, EUR)
  • Test donations using the built-in test buttons

StreamGoals Initial Configuration

  1. Open StreamGoals in your web browser
  2. On the Dashboard, connect to Streamer.Bot:
    • Enter IP address (usually 127.0.0.1)
    • Enter port (usually 8080)
    • Click Connect
  3. Go to Settings and configure:
    • Set your goal targets for each platform
    • Enter current follower/subscriber counts
    • Choose colors and labels for each goal
    • Configure overlay dimensions and appearance
  4. Go to the Overlay tab and copy the generated URL
  5. In OBS, add a new Browser Source:
    • Paste the overlay URL
    • Set width and height to match your settings
    • Uncheck "Shutdown source when not visible"
    • Check "Refresh browser when scene becomes active"

Troubleshooting

Connection Issues

YouTube subscribers not updating
  • Verify YouTube Data API v3 is enabled in Google Cloud Console
  • Check that zz_youtubeApiKey global variable is set correctly
  • Ensure YouTube account is connected in Streamer.Bot
  • Check API quota usage in Google Cloud Console
  • Verify the imported StreamGoals actions are working

Platform-Specific Issues

TikTok events not working
  • Ensure TikFinity Desktop App is running and connected
  • Check TikFinity WebSocket connection in Streamer.Bot
  • Verify TikTok account is properly logged in to TikFinity
  • Try disconnecting and reconnecting TikFinity WebSocket
Kick events not working
  • Ensure Kick.Bot DLLs are in the correct dlls folder
  • Verify Kick account login was successful
  • Check that Kick.Bot action was imported correctly
  • Try reinstalling Kick.Bot if events stop working
  • Set Kick channel name in StreamGoals settings
Donations not tracking
  • Verify StreamElements or StreamLabs is connected to Streamer.Bot
  • Check that donation platform integration is active
  • Test with small donation to verify connection
  • Ensure currency settings match your preferred currency

Frequently Asked Questions

Q: What platforms does StreamGoals support?

A: StreamGoals supports Twitch, YouTube, TikTok, and Kick for follower/subscriber tracking, plus StreamElements and StreamLabs for donations.

Q: How do I backup my StreamGoals configuration?

A: Your settings are automatically saved in the overlay URL! Just bookmark it or use the Export JSON feature. The URL contains all your goals, settings, colors, and preferences.

Q: Can I use custom fonts from Google Fonts?

A: Yes! Select "Custom Font Name" and enter any Google Fonts family name (like "Roboto" or "Open Sans"). Make sure the font is available on the system running OBS.

Q: How accurate are the currency conversions?

A: StreamGoals fetches real-time exchange rates from a reliable API and updates them automatically. Rates are typically accurate within a few hours of market changes.

Q: Can I create different overlay configurations for different scenes?

A: Yes! Configure your overlay settings, copy the URL, and bookmark it with a descriptive name. You can create multiple configurations (like "Twitch Only" or "All Goals") and each gets its own unique URL.

Q: What's the difference between "Auto-Increment" and regular goals?

A: Auto-increment goals automatically increase their target when reached (like a "moving goalpost"). Regular goals stay at the same target. This keeps momentum going during successful streams.

Q: Why do some goals show current progress higher than the target?

A: This happens when you've exceeded your goal target. The progress bar will show 100% complete, but the current value continues to increase. Consider using auto-increment goals to automatically raise targets when achieved.

Q: Can I hide certain goals from the overlay?

A: Yes! In Settings → Overlay Settings, you can disable any goal by unchecking "Show on Overlay". Only enabled goals will appear in the overlay rotation.

Q: How do I test if everything is working before going live?

A: Use the test buttons on the Dashboard: "Test +1 Twitch Follow", "Test +$10 USD", etc. These simulate real events so you can verify the overlay updates correctly.

Known Issues & Limitations

Kick Integration (Beta)

Kick doesn't offer an official API like Twitch. The Kick.Bot integration is excellent but has limitations:

  • Missing some payload information (avatars, badges, viewership)
  • Occasional connection issues requiring reinstallation
  • Beta functionality that may need troubleshooting

URL Length Limitations

Settings are stored in URLs, which have browser-specific length limits:

  • Most browsers support URLs up to 2000+ characters
  • Very complex configurations may approach this limit
  • Use JSON export/import for very large configurations
  • Configuration compression reduces URL size significantly

Performance Notes

  • WebSocket connections: Keep Streamer.Bot running for real-time updates
  • Browser performance: OBS Browser Sources are lightweight
  • Memory usage: Configuration stored in memory, not localStorage
  • Update frequency: Events processed in real-time as they occur
