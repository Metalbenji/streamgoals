📺 Netlify + URL Storage Setup

🔗 Overlay URL for OBS:
📐 OBS Dimensions: Width: 800px, Height: 70px
  1. In OBS Studio, add a new Browser Source
  2. Copy your Overlay URL above and paste it into the URL field
  3. Set Width and Height to match your overlay settings (check Settings → Overlay Settings)
  4. IMPORTANT: Check "Shutdown source when not visible" and "Refresh browser when scene becomes active"
  5. Set FPS: to 30
  6. The overlay will load with all your settings embedded in the URL
  7. Use the Start/Stop buttons above to control the overlay display
✅ Smart URL Configuration
Your settings are automatically saved in the URL - no more lost configurations! Just copy the overlay URL to OBS and everything works perfectly.
